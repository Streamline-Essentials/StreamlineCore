# StreamlineDiscord: Start Here

> Do not edit this file. It is replaced every time the server starts.
> Make your changes in the other files in this folder instead.

## What this module does

StreamlineDiscord connects your Minecraft server to your Discord server.

- Minecraft chat shows up in a Discord channel.
- Messages in that channel show up in Minecraft chat.
- Players can link their Minecraft account to their Discord account.
- The bot can post server starts, joins, leaves, deaths and more in Discord.

All files named in this guide sit in this same folder.

## Before you start

Turn on Developer Mode in Discord.
You find it under User Settings, then Advanced.
Now you can right-click things in Discord to copy their ID.

## Step 1: Make the bot

1. Open the Discord Developer Portal: https://discord.com/developers/applications/
2. Click "New Application" and give it a name.
3. Open the "Installation" page and set the install link to "None".
4. Open the "Bot" page.
5. Turn off "Public Bot" so strangers cannot add it.
6. Turn on all three "Privileged Gateway Intents" switches.
7. Click "Reset Token" and copy the token. Keep it secret!

Without those three switches, the bot cannot read Discord messages.

## Step 2: Invite the bot

1. Open the "General Information" page and copy the "Application ID".
2. Paste this link into your browser, with your ID at the end:
   `https://discord.com/oauth2/authorize?scope=bot+applications.commands&permissions=8&client_id=`
3. Pick your Discord server and click "Authorize".

The bot now joins your server with admin rights.

## Step 3: Fill in config.yml

1. Open `config.yml` in this folder.
2. Paste your token after `token:` between the quotes.
3. Right-click your Discord server's name and click "Copy Server ID".
4. Paste that number after `main-guild-id:`.
5. Save the file and restart your Minecraft server.

If the server ID is left at 0, the module turns itself off.

Other handy settings in `config.yml`:

- `prefix` is what starts typed bot commands. The default is `>>`.
- `activity` sets the status text under the bot's name.
- `full-disable` turns the bot off on this server.
- `slash-commands` turns Discord's slash commands on or off.

## Who can use the setup commands

Most bot commands only work for the owner of the Discord server.
This covers channel linking, events, reload and restart.
To let your staff use them, copy their role's ID.
Put it in `super-admin-roles` in `config.yml`, like this:
`super-admin-roles: ["1234567890987654321"]`

Anyone can use the help, ping, verify and unverify commands.

## Linking a channel to Minecraft chat

1. Go to the Discord channel you want to link.
2. Type `/channelset type:GLOBAL_NATIVE` and send it.

That is it. Chat now flows both ways between the game and that channel.

To unlink it, type `/channelremove` in that channel.
To see what a channel is linked to, type `/channels here:True`.

Other link types exist for one server, guilds, parties and chat channels.
Ask on our Discord if you need one of those.

## Event messages

The bot can post game events in a linked channel.
It can post these six events:

- The server starting up.
- The server shutting down.
- A player joining.
- A player leaving.
- A player earning an advancement.
- A player dying.

Advancements only show on Spigot or Paper servers.
Set `server-name` under `server-events` in `config.yml` to name your server.

New links start with no events turned on.
The easy way: type `/add_all_events` in the linked channel.
Pick "Every channel" to turn them on for all your links at once.

To turn on single events instead:

1. Type `/channels here:True` in the linked channel.
2. Find the line that ends with DISCORD_TEXT.
3. Copy the long id at the start of that line.
4. Type `/events action:Add Event type:All identifier:` and paste the id.

Use "Remove Event" or "Clear All" to turn events off again.

The `server-events` part of `config.yml` turns each event on or off everywhere.

## One bot for a whole network

Using Velocity or BungeeCord? You only need one bot, on the proxy.
Install the module on your game servers too, but leave their bot off.
They then pass deaths, advancements, starts and shutdowns to the proxy's bot.
The proxy posts joins and leaves itself.

This works best when Streamline uses Redis or a MySQL database.
Without either, game servers can only pass events while a player is online.
Shutdown messages may then go missing.

Give each game server a name with `server-name` under `server-events`.
The `event-relay` part of `config.yml` turns this on or off.

## Linking accounts (verification)

1. The player types `/verify` in Minecraft.
2. The game shows them a short code.
3. In Discord, they type `/verify` and paste the code.

With typed commands, that is `>>verify` and the code.
To unlink, the player types `/unverify` in Minecraft or Discord.

In `config.yml`, under `verification`, you can do more on linking.
You can give Discord roles or run game commands.
Give the bot the "Manage Roles" permission for roles to work.

## Changing what the bot says

Three things work together:

- `messages.yml` holds the plain text of every bot message.
- The `embeds` folder holds fancy boxed messages, one file each.
- `messaging.yml` picks which one each message uses.

In `messaging.yml`, each message has one of these:

- `default` sends the plain text from `messages.yml`.
- An embed's file name sends that embed from the `embeds` folder.
- `disabled` sends nothing at all.

To make your own embed, copy a file in `embeds` and rename it.
Edit the copy, then put its name in `messaging.yml`.
Changes work on the next message. No restart is needed.

## Turning bot commands on or off

Type these in Minecraft. You need the permission `streamline.command.streamlinediscord.admin`.

- `/streamlinediscord admin commands disable <command>` turns a bot command off.
- `/streamlinediscord admin commands enable <command>` turns it back on.
- `/streamlinediscord admin slashcommands disable <command>` hides only its slash version.
- `/streamlinediscord admin slashcommands enable <command>` brings the slash version back.
- `/streamlinediscord admin slashcommands reregister` sends every slash command to Discord again.
- `/streamlinediscord admin messages reload` reloads the message files and checks your embeds.
- `/streamlinediscord admin messages reset <file>` puts one message file back to its default.
  Use `messages.yml`, `messaging.yml` or an embed like `on-advancement.json`.
- `/streamlinediscord admin messages reset ALL` puts every message file back.
  Old files are kept in `backups/message-resets/`.

The bot only updates Discord's slash list when something really changed.
Use `reregister` if the slash list in Discord looks wrong.

## Something is wrong?

**The bot is offline.**
Check that the token is right and has no extra spaces.
Check that `main-guild-id` is not 0.
Read your server console for red error lines.

**The bot is online but ignores chat.**
Turn on all three "Privileged Gateway Intents" switches. Then restart.

**A command says I am not allowed.**
Only the Discord server owner can use it by default.
Add your role to `super-admin-roles` in `config.yml`.

**Slash commands are missing.**
Check that `slash-commands` is true in `config.yml`.
Then run `/streamlinediscord admin slashcommands reregister` in Minecraft.
Discord can take a minute to show them.

**No join or death messages show up.**
Turn on events for that channel, as shown above.
Death and advancement messages need a Spigot or Paper server.

**A message never shows up.**
Check `messaging.yml`. It may be set to `disabled`.
